These pages describe current behavior. Keep plans, session records, progress
reports, candidate manifests, execution logs, screenshots, and evaluation results
outside tracked documentation. Use ignored `.agents/` workspace directories or
the external specifications repository. Reusable tests and evaluation tools can
remain versioned without their run output.
