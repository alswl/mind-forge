# Historical triage evidence (sanitized copy)

These files preserve historical CLI observations, not a fresh verification of the current candidate.
Before publication, local user paths and private repository roots were replaced with synthetic paths;
private source revisions were removed. User/host-specific review URLs in the surrounding reports
were replaced with loopback examples. No service is started by those links.

`sha256.json` hashes the sanitized published files. Historical document-content hashes in
`inputs.json` describe the original inputs; those private inputs are not included or independently
verifiable here. Sanitized path strings are illustrative and are not runnable original coordinates.
